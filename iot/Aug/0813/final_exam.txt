본 시험은 생성형 AI 사용을 허용합니다.
AI를 사용하는 것 자체는 감점 대상이 아닙니다.
그러나 AI가 생성한 결과를 검증하지 않고 그대로 제출하는 것은 좋은 답안으로 평가하지 않습니다.
여러분은 AI에게 문제를 잘 설명하고(Prompt), AI가 제시한 답변을 분석하고(Evaluate), 신뢰할 수 있는 출처를 통해 내용을 검증하고(Verify), 필요한 경우 코드를 수정하여 최종 결과를 만들어야 합니다.
따라서 본 시험에서는 정답 코드 자체뿐만 아니라 AI 활용 과정, 출처 조사, 오류 검증, Tinkercad 실행 및 코드 설명 능력​을 함께 평가합니다.
AI를 잘 사용하는 학생보다 AI가 제시한 답을 검증하고 자신의 것으로 만들 수 있는 학생을 높게 평가합니다.

시험 목적
본 시험은 Arduino UNO의 기본적인 하드웨어 및 C++ 프로그래밍 개념을 이해하고 있는지를 평가하는 동시에, 생성형 AI를 활용하여 문제를 해결하고 AI가 제시한 결과를 검증·수정·설명하는 능력을 평가한다.

AI 사용 규칙
시험 중 생성형 AI를 자유롭게 사용할 수 있다.
단, 다음 사항을 반드시 준수한다.
	- AI에게 입력한 프롬프트를 제출한다.
	- AI가 최초로 생성한 답변 또는 코드를 제출한다.
	- AI가 제시한 정보의 정확성을 확인하기 위해 출처를 조사한다.
	- 출처는 가능한 한 공식 문서 또는 신뢰할 수 있는 기술 문서를 우선한다.
	- AI가 생성한 코드에 오류가 있거나 개선할 부분이 있다면 직접 수정한다.
	- 최종적으로 Tinkercad에서 코드를 실행하여 정상적으로 동작하는지 확인한다.
	- AI가 작성한 답변을 이해하지 못한 상태로 그대로 제출하지 않는다.
	- 출처가 확인되지 않는 내용을 사실인 것처럼 작성하지 않는다.
출처 작성 방법
다음 형식으로 작성한다.
	출처명 / 웹사이트 / URL / 확인한 내용
	예:
	Arduino Language Reference / Arduino 공식 문서 / URL / digitalWrite()의 기능을 확인함
	Arduino 공식 Language Reference에는 디지털 I/O, 아날로그 I/O, 시간 관련 함수 등을 포함한 Arduino 프로그래밍 요소가 정리되어 있다.

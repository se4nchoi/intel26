03. 센서류 / Sensors

Retroreflective Sensor + Reflector
센서와 반사판(Reflector)이 서로 마주 보도록 설치하여 광선이 끊어지는지를 감지한다.
B접점 개념 Reflector 필요 물체 감지
핵심: 센서 ↔ Reflector 사이의 빛이 물체에 의해 차단되는지를 확인한다.
Light Array Emitter + Light Array Receiver
여러 개의 평행한 빛을 이용하여 물체가 어느 정도 영역을 가리고 있는지를 감지한다.
8 Beam Numerical Digital Analog
Numerical 8개의 빔 상태를 하나의 숫자값으로 표현. 각 비트가 각 빔을 나타낸다.
Digital 각 Beam을 개별적인 ON/OFF 비트로 확인.
Analog 차단된 Beam의 개수에 따라 0~10V 범위의 아날로그 값으로 표현.
암기: Digital = 비트별 확인 / Numerical = 숫자 하나로 확인 / Analog = 전압값으로 확인
Diffuse Sensor
센서에서 나온 빛의 반사를 이용하여 물체의 존재 여부를 감지한다.
Digital 물체 감지 A접점 개념
핵심: 물체를 감지하면 센서의 Digital 신호가 ON 상태가 된다.

04. 오브젝트 생성 / 제거

Emitter

장면(Scene)에 사용할 Item을 생성하는 기능.

  • Base to Emit
    아래에 깔리는 Base를 생성
    예: Pallet, Square Pallet, Stackable Box
  • Part to Emit
    실제 생산물 또는 기본 오브젝트를 생성
    예: Box, Raw Material, Product Lid 등
필기: Emitter = 물체를 만들어서 공정에 투입

Remover

특정 영역에 들어온 Item을 제거하는 기능.

  • 생성된 물체를 장면에서 제거
  • Base 제거 가능
  • Part 제거 가능
  • Tag를 ON/OFF하여 활성화 또는 비활성화
필기: Remover = 공정이 끝난 물체를 제거

★ 핵심 암기

  • Orbit → 주변을 돌며 보는 시점
  • Fly → 공간을 날아다니는 시점
  • First Person → 1인칭 시점
  • Retroreflective → Reflector와 함께 사용
  • Light Array → 8개의 Beam을 이용하여 감지
  • Numerical → 여러 Beam 상태를 숫자로 표현
  • Digital → ON/OFF 또는 비트 단위로 표현
  • Analog → 전압값으로 표현
  • Emitter → 오브젝트 생성
  • Remover → 오브젝트 제거
